# NetGuard AI - Demo & Test Traffic Data

> **IMPORTANT NOTICE: This directory contains test and demo input data only.**
> - It is **NOT** used for training the Machine Learning models.
> - The production models were trained strictly on the official NSL-KDD benchmark training dataset (`ml/data/raw/KDDTrain+_20Percent.txt`).
> - The CSV file located here (`sample_network_traffic.csv`) is provided strictly for functional testing, API validation, and UI file upload verification.
> - It contains 30 unlabelled real network flow captures (15 benign communications and 15 intrusion attempts) derived from the NSL-KDD test set.
